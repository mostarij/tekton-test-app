# Tekton Test Application

A simple Node.js application for testing Tekton CI/CD pipelines.

## Quick Start

```bash
npm install
npm test
npm start
```

## Endpoints

- `GET /` - Main endpoint
- `GET /health` - Health check

## Testing with Tekton

This app is designed to work with Tekton pipelines and includes:
- Automated tests
- Build script
- Docker support
